*Sistema de Gerenciamento de Biblioteca:*

O projeto é desenvolvido na linguagem de Python e tem a funcionalidade para gerenciar o acervo de uma biblioteca. 
O Código permite cadastrar livros, controlar empréstimos e devoluções, buscar títulos e manter tudo salvo de forma permanente em um arquivo csv.


*Para abrir o programa, você deve*
se certificar de ter o Python 3 instalado no computador;
abrir o terminal e abrir a pasta do projeto;
digitar o comando e apertar enter:

```bash
python main.py
